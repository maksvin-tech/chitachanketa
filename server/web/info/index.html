OMR Ankete

Interni alat Ureda za upravljanje kvalitetom, Sveučilište u Zagrebu

Program očitava skenirane papirnate ankete (studentske ankete o studiju i procjena nastavnika), izrađuje tablice rezultata i PDF izvještaje za sastavnice Sveučilišta te ih sprema u Google Drive ureda.

Program koriste samo djelatnici i suradnici ureda; pristup je zaštićen lozinkom.
